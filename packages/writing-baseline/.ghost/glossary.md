# standard

Shared language guidance that is not specific to any brand. Every rule carries
one of two authority labels. An **Obligation** is a requirement brand
preference cannot waive: honesty, accessibility, and functional integrity. The
brand controls how it is expressed, not whether it holds. A **Default** is a
starting position that protects copy from generic phrasing; explicit brand
guidance may deliberately replace it. When a default with a paired check is
overridden, adapt or remove the check flag in the same change.

# foundation

The chapters where a brand's language decisions live: voice, tone, and
mechanics. Each chapter carries usage law that holds whatever the brand's
answers turn out to be, conventions a brand may replace, and known gaps that
only a human can answer. Pull every chapter whose subject the task touches.
Never fill a known gap and present the value as the brand's.

---

Node bodies follow one shape: `## Usage` carries the decision logic; `## Rules`
carries requirements a reviewer can assess in the finished copy; `## Never`
pairs each rejected move with its replacement. Standard nodes list one rule
per `###` heading so checks can reference each rule by name.

To adapt this baseline to a brand, change the manifest id, answer each known
gap with rewrite pairs from the people who own the voice, and delete any
default the brand has deliberately replaced along with its paired check flag.
