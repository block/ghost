## Usage

These empirical defaults record choices that recurred across repeated unsteered generations, not universal design faults. Several together can indicate missing source guidance; one alone usually does not. Repair the missing brand information rather than banning a shape that documented brand guidance uses.

## Rules

- Frequency rather than a single occurrence identifies the copy-rhythm tells: five or more em dashes in one view, or three or more aphoristic rebuttal cadences such as "Not X. Y.", indicate generated rhythm.

## Never

- Never use `translateY` hover movement paired with a growing shadow as automatic premium polish — instead give a visible state change through a documented change in color, background, border, text, or figure-ground.
- Never invent an indigo, blue, or violet accent, especially `#4f46e5`, `#6366f1`, `#2563eb`, `#8b5cf6`, and close neighbors, when no supplied brand guidance or task calls for it — instead use the declared palette rather than swapping in another generic accent.
- Never choose a dark page or product shell without support — instead use the supported background, and treat darkness as fidelity where a brand identity or applicable interface decision establishes dark as its normal background.
- Never add invented gradient page or section backgrounds, gradient-filled actions, gradient text, or frosted glass panels — instead use the supported background, and reserve gradient or blurred-media treatment for the specific source-derived one an identity or applicable interface node establishes, which does not license generic glassmorphism.
- Never put a thick colored border on one side of an otherwise thin or unbordered rounded container — instead use full borders, spacing, documented status treatment, or brand-owned ornament.
- Never use rounded assistant or support bubbles with initials-circle avatars when the task does not require conversation UI — instead set plain text on the surface or use the documented product container.
- Never write headings or proof language that could move to another product unchanged, such as "Simple, transparent pricing," "Welcome back," "Unlock growth," and "All-in-one platform" — instead name the actual subject, evidence, or next step.
- Never nest cards inside cards or convert every content group into a rounded container — instead use one surface level per region and build hierarchy with type, spacing, alignment, rules, or a documented component.
- Never use the big-number, small-label, supporting-stat-row template as automatic proof — instead give a metric prominence only where it is real, useful data doing evidentiary work.
- Never use repeated uppercase tracked kickers above headings or isolated italic words as automatic emphasis — instead establish hierarchy through scale, weight, spacing, or documented color, and use an eyebrow or italic only where a documented brand signature uses either intentionally.
- Never default to warm cream, sand, or beige backgrounds, including `--cream`, `--sand`, `--parchment`, or `--linen` — instead use the documented background, a true off-white, or a deliberate color choice, using warmer colors in accents and type unless brand guidance establishes a warm background.
- Never center headline, body, action, and metrics across a whole view as the automatic composition — instead choose alignment from the content's reading order on the brand's grid, and center only a sparse focal statement.
- Never set billboard-scale statistics in operating or information-dense work, with display-size numerals dominating a slide or section that also contains copy and tables — instead size a number for its content role while keeping clear contrast, and let a real headline metric take prominence when it is doing evidentiary work.
- Never use chips, capsules, or pills as ambient visual texture — instead use a pill only for an action, a compact label, or a rare deliberate emphasis rather than as filler.
- Never attach sequence numbers to unordered categories as visual flair, or substitute icon sets for such numbers with no semantic content — instead use numbers only where they communicate order, quantity, priority, or a stable reference, and give unordered categories plain labels or meaningful icons.
- Never leave repeated em dashes or repeated aphoristic rebuttal cadences such as "Not X. Y." standing in copy — instead rewrite the passage into direct, natural prose.
