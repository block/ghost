## Usage

Public-page defaults connect an outcome to product evidence. Section order and emphasis follow the content rather than a preset landing-page recipe.

## Rules

- Lead with the intended audience’s ambition or outcome, then support it with product evidence.
- Reduce a very large headline, full-bleed image or video, or dark section if product facts, terms, or actions become harder to find.
- Keep navigation and footer smaller than the page content so they do not dominate it.
- Use a background change to mark a new subject; set the text color for each full-width section.
- Put comparable prices, specifications, and terms in tables; give a single figure display prominence only when it makes the page’s point, with its label at reading size.
- Set marketing FAQs as expandable editorial text rather than a card grid.
- Keep horizontal margins in an inner content wrapper while a full-width outer section sets the background and vertical spacing.

## Never

- Never default to a centered hero, feature grid, statistics strip, testimonial, and FAQ — instead choose sections and order for the actual content.
- Never use a stock photograph or texture merely to fill a gap — instead use relevant product evidence or a type-led composition.
