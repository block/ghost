# Recipe: Use Plain Words

Apply these restrictions to authored guidance and explanations to the human.
They govern writing, not source identifiers, paths, quoted evidence, or literal
technical uses. Do not change a source name to satisfy a writing rule.

Do not use:

- `ratify` or `ratification`; use approve or approval.
- `provenance` or `attribution`; use source or name who supplied the decision.
- `furniture`; name the element.
- `corpus`; use guidance or package.
- `taxonomy`; use vocabulary or grouping.
- `standing`; name the authority or scope.
- `altitude`; state whether guidance is universal or conditional.
- `temperature` as a metaphor for brand character; name tone, pace, density,
  or formality.
- `laundering`, `ladder`, `rung`, `front door`, or `junk drawer` as metaphors;
  name the action, order, entry point, or purpose.
- `brand soul`; name the specific brand decision.
- `worldview` when approach, principle, or reason is clearer.

Do not describe flat guidance files as parents, children, or nested guidance.
Use `artifact` only when page, screen, document, presentation, file, or output
would be less precise. Avoid flowery language, academic phrasing, internal
jargon, and clever labels for ordinary design work.

## Name the observable choice

When a word hides the instruction, replace it with what the agent must do.
These are editing prompts, not blanket bans on literal or technical uses.

| Instead of... | Name... |
| --- | --- |
| `signal` | the exact cue: color, copy, position, size, motion, contrast, or timing |
| `restraint` | the concrete limit: count, spacing, frequency, contrast, ornament, or emphasis |
| `personality` | the observable behavior: tone, pace, density, formality, or visual treatment |
| `thing` | the actual page, screen, document, component, example, or output |
| `carry the field`, `let the signal land`, or similar phrasing | the background, spacing, hierarchy, or emphasis to apply |
