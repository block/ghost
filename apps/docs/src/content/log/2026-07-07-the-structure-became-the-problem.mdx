title: the structure became the problem
date: 2026-07-07
summary: ghost replaced fixed buckets with a designed structure of trees, edges, and bindings, watched it reproduce the same resolver, and deleted it down to a flat set of described files.
---

After the buckets came a better structure. That was the plan, and we built it.

A surface was an author-named group. Containment was a strict tree, so a node placed in a folder cascaded down to everything beneath it. Composition crossed the tree through typed edges, because a real case showed that what combines to serve a request is not always what contains it. Paths lived in a separate binding layer so the guidance itself stayed portable. Packages could extend other packages, which gave us the shared-brand story: one company contract, many products inheriting it.

Each of those decisions has a note behind it. Each note closes a fork with an argument. Read in sequence they are convincing.

## what it cost to use

Placing a node became a design act. An author with a sentence about trust had to decide which surface owned it, whether it should cascade, whether a sibling needed an edge, and whether the edge kind we allowed described their situation.

We wrote lint rules to teach the placement. We banned dotted ids so hierarchy lived in one field. We fixed a leak where sibling folders bled into each other. We renamed the traversal vocabulary twice because nobody outside the repo could hold the spine and hub metaphors.

Then a composition-heavy case with no repository behind it arrived, and the tree was not the primary structure at all. The edges were. The tree was an artifact of how the first case happened to sit in a filesystem.

That is when it became clear what we had rebuilt. A resolver. The same one we removed with Relay, now expressed as topology instead of configuration. Both existed to reconstruct which guidance applies before the model saw any of it.

## where applicability actually lives

The model on the other end reads prose and matches a task against a description. It does not need a tree to know that a rule about irreversible actions applies to the screen it is changing. It needs the rule to say so.

So the structure came out. Cascade, containment, typed edges, incarnation filters for cross-medium projection, cross-package inheritance, the path binding layer, and the surface concept itself. The checks that survived moved to one flat directory and stopped being routed at all: every check is offered, and the reviewing agent decides which ones bear on the diff.

What is left is a set of markdown files in one directory. A file states guidance in prose and carries a description that says when it applies. Universal guidance says so plainly. Narrower guidance names its condition. Nesting into folders is browsing convenience with no meaning attached.

Altitude moved from the filing system into the sentences.

## what we gave up

The shared-brand story is gone for now. A company contract extended by many products was the most requested shape and the hardest thing to keep, because inheritance means a child can silently override a parent rule and nothing in the output shows that it happened. Copying a package and owning the copy is cruder and visible.

Two structures failed in the same way, five weeks apart. The buckets forced authors to file ideas where the ideas did not fit. The graph forced them to place ideas where the products did not sit. Both were designed to make selection predictable for the machine before anyone had watched a machine select.
