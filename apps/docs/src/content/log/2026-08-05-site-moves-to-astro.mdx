---
title: the site moves to astro
date: 2026-08-05
summary: the thesis site is now statically generated, making room for a public record of how ghost changes.
---

The ghost site began as a React application serving one static thesis page. The page needed less runtime and we had no place for project updates.

The site now builds with Astro. The thesis is static HTML, the gather example remains a small React island, and missing routes get real pages instead of application redirects. We removed dependencies the live site never used.

This entry starts the ghost log: a public record of material project changes and the reasoning behind them. The CLI help remains the source for current command behavior.
