---
title: the site moves to astro
date: 2026-08-05
summary: the thesis site is now statically generated, making room for a public record of how ghost changes.
---

The ghost site began as a React application serving one static thesis page. That was more runtime than the page needed and left no simple place for project updates.

The site now builds with Astro. The thesis is static HTML, the gather example remains a small React island, and missing routes have a real page instead of an application redirect. The move also removes dependencies that the live site did not use.

This entry starts the ghost log: a public record of material project changes and the reasoning behind them. It is not product documentation or a roadmap. The CLI help remains the source for current command behavior.
